# `zxxk-zujuan-paper-downloader` — **v2.0 飞跃版（重大更新）**

> 一个基于 **Tampermonkey (篡改猴)** 的用户脚本，专为优化“学科网 / 组卷网”试卷的下载、打印与个人题库导出体验而设计。
> **v2.0**：从“纯净打印工具”飞跃为“试卷 + 答案 一体化导出工具（离线 HTML / ZIP）”，并带来强大的图片嵌入、并发控制与抗封禁保护。

---

## 🚀 为什么这是一次「飞跃」

v1.x 专注解决打印与排版问题，v2.0 则把目标扩展到“把网页上的题目、公式、答案 **彻底带走**（离线）”，实现：

* **试卷离线打印（更稳更清爽）** —— 延续并强化 v1 的打印优化策略；
* **个人题库导出（真正的离线包）** —— 把每道题目与答案导出为单个 HTML 或打包成 ZIP；
* **答案合集（单文件或 ZIP）** —— 自动抓取页面答案、解析与答案图片，生成便于批阅/打印/归档的合集；
* **图片/公式嵌入（Data-URI）** —— 能把页面上所有公式与图片转成 Data-URI，生成 **真正离线可打印的 HTML**（可选）；
* **智能命名/去重/并发/防封控件** —— QID 智能命名、按 QID 去重、可配置的并发与请求延迟、自动检测 429 并执行封禁保护（默认 10 分钟）。

---

## ✨ v2.0 亮点一览

### 核心新特性

* **答案合集导出（HTML & ZIP）**

  * `导出答案合集 HTML`：生成单个 HTML 文件，内嵌题目 & 答案（图片可嵌入或保留外链）。
  * `导出答案 ZIP`：生成 ZIP，包含 `answers_html/` 和 `answers_images/`（若不嵌入图片则把图片单独保存到文件夹）。
* **题目离线导出（HTML & ZIP）**

  * 支持将个人题库中所有题目导出为：单 HTML（内嵌资源）或 ZIP（每题独立 HTML + 原始图片）。
* **图片嵌入（Data-URI）模式**

  * 可将 SVG/PNG/JPG 等全部内嵌到 HTML，确保**在离线环境下也可以完整显示公式**（tradeoff：文件会很大）。
  * 提供 **“最大嵌入总 MB”** 阈值防止生成巨大的文件。
* **智能文件命名**

  * 图片 / 文件命名规则例如：`QID_23157943_ans1.png`、`QID_23157943_idx1.html`，便于检索与批量处理。
* **并发 / 延迟 / 封禁保护**

  * UI 可调整 `CONCURRENCY`、`INTER_REQUEST_DELAY_MS`、`FETCH_RETRY`、`BLOCK_DURATION_MS`。
  * 自动在遇到 429/403 时记录并短期阻塞（默认 10 分钟），避免快速封禁账号/IP。
* **兼容性与稳健性**

  * 对页面上 `img`、`srcset`、inline `style` (url())、computed `background-image` 都做了处理。
  * 对答案可能的“外链解析接口”（如 `getAnswerAndParse`）做了保守型适配（如存在可利用的外链会尝试抓取）。
* **去重（按 QID）**

  * 自动检测并去重重复题或重复答案（你的页面中重复题会自动合并）。

### 仍保留 / 强化的 v1 特性

* 继续**强力打印样式修复**：避免右侧被裁切、强制换行、表格/公式不溢出、轻微缩放补偿等；
* 自动隐藏知识点 / 来源 / 组卷次数等干扰元素，打印后自动恢复页面（不破坏原页面）；
* 更加友好的控制面板（UI 内可直接操作所有导出与阈值设置）。

## 📥 安装（快速）

1. 安装 **Tampermonkey**（或其他支持 Greasemonkey 元数据的用户脚本管理器）。
2. 新建脚本，复制 `v2.0` 的用户脚本内容（或在 GreasyFork 上发布的链接安装）。
3. 打开学科网 / 组卷网（`https://zujuan.xkw.com/`）的【个人题库】或试卷详情页，等待面板出现。
4. 使用面板上的按钮进行导出、嵌入或打印。

> **小提示**：若已安装旧版，请先在 Tampermonkey 中禁用/移除旧脚本，然后再启用 v2.0，以避免冲突。

## 🧭 使用指南（简洁流程）

### 1) 纯净打印（保留 v1 的体验）

* 在试卷详情页点击 `纯净打印` 按钮 → 会生成重构后的打印预览并调用 `window.print()` → 打印后页面自动恢复。

### 2) 导出个人题库 / 题目

* 打开个人题库页面（或包含 `.tk-quest-item` 的页面）。
* 面板 → `生成题目离线 HTML`：将所有题目合并到单个 HTML（可离线打开并打印）。
* 面板 → `生成题目 ZIP`：每题单独 HTML，并把先前页面的资源（图片）内嵌或保存到 ZIP。

### 3) 导出答案合集（最受欢迎的）

* 点击 `导出答案合集 HTML`：脚本会尽力打开页面的“显示全部答案和解析”（若有），抓取答案与解析内图片并可选嵌入 Data-URI。
* 点击 `导出答案 ZIP`：答案按题目生成 HTML，并把图片/公式文件放到 `answers_images/` 中，利于批量保存/阅卷。

### 4) 高级控件（面板）

* **并发**：并发网络请求数（默认 3）。
* **延迟(ms)**：每次请求的基本间隔（默认 120ms）。
* **重试**：失败请求的最大重试次数（默认 2）。
* **封禁 ms**：遇到 429/403 后执行的保护时长，默认 600000（10 分钟）。
* **最大嵌入总 MB**：控制 Data-URI 嵌入时的总体上限（默认 8MB）。
* **去重 (QID)**：按题目 QID 去重，默认开启。

* **个人题库 ZIP**：`personal_questions_2026-02-17_14_23_12.zip`

## ⚠️ 注意事项（请务必阅读）

* **文件体积**：Data-URI 嵌入会把所有图片转成 Base64，文件体积会显著增大。建议在 `MAX_EMBED_TOTAL_MB` 设置一个合理阈值（默认 8MB）。若想得到较小的 ZIP，请取消“嵌入”选项，让脚本把图片作为单独文件保存到 ZIP。
* **访问频繁被封**：站点会对短时间频繁的资源请求做流量封禁（如 10 分钟封禁）。已实现对 429/403 的检测并触发 `BLOCK_DURATION_MS`，请调整并发与延迟减少被封风险。
* **跨域 / CORS**：某些外部资源（特别是第三方 CDN 或受限的 SVG）可能不能被 `fetch`，这会导致无法嵌入。脚本会把失败的 URL 列入日志，保留外链或生成 fallback 文件。
* **页面变动**：站点 DOM 若有重大变更（类名改动等），脚本的 selector 可能需要更新。你可以把页面的一段 HTML 片段给我，我能帮你适配更鲁棒的 selector。
* **重复题**：页面中有题目重复出现的情况，启用 “去重(QID)” 可以避免重复导出。
